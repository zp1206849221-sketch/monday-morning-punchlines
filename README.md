# Monday Morning Punchlines

One joke about Monday mornings, written by `main.py` to `/output/entry.txt`:

> Friday me booked Monday me a 7 a.m. spin class. Monday me showed up only to identify the traitor.

Friday-you makes ambitious plans; Monday-you has to live with them — and knows exactly who to blame.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Python standard library only; no dependencies.
